# Agriculture AI System

An AI-powered agriculture application that provides:

- Crop Recommendation
- Fertilizer Recommendation
- Sugarcane Leaf Disease Classification

## Technologies

Python
Flask
Scikit-learn
TensorFlow
NumPy
HTML
CSS
JavaScript

## Machine Learning Models

### Crop Recommendation
Input:
- Temperature
- Humidity
- Moisture
- Soil Type
- Nitrogen
- Potassium
- Phosphorous

Output:
Recommended crop

### Fertilizer Recommendation
Input:
- Temperature
- Humidity
- Moisture
- Soil Type
- Crop Type
- Nitrogen
- Potassium
- Phosphorous

Output:
Recommended fertilizer

### Leaf Disease Classification

Input:
Sugarcane leaf image

Output:
- Healthy
- Mosaic
- RedRot
- Rust
- Yellow
